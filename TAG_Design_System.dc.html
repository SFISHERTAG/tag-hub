Usage Guidelines

Gold (Interactive Only)

Gold (#e0a324) is reserved for interactive elements and brand identity. Never use it for status indication—it would be confused with "selected" state. Use the semantic colors (green, warn, red) for status instead.

Light vs Dark Mode

Light mode: White surfaces, black hairlines for structure, minimal shadows.

Dark mode: Stepped surface colors, less visible borders, lifted shadows for depth.

Contrast & Accessibility

  • Text on #cc901b should be #050505 (black)
  • Text on #1a6b45 should be #ffffff (white)
  • Text on #b02a1f should be #ffffff (white)
  • All interactive elements have focus ring: 2px solid #cc901b with 2px offset
  • Minimum tap target size: 44x44px (mobile accessibility)
  • Link underlines visible by default; remove only when context is clear

Component Spacing

  • Button padding: 11px (vertical) × 16px (horizontal)
  • Button gap: 12px minimum
  • Form field padding: 10px × 12px
  • Card padding: 20px
  • Section padding: 40px

Best Practices

  • Status badges: Always pair color with an icon (✓, ⚠, ✗) for colorblind accessibility
  • Buttons: Use Primary for main actions, Secondary for alternatives, Success/Danger for semantic actions
  • Forms: Always label inputs; use placeholder text as hints only, not labels
  • Typography: Never go below 12px; use secondary/tertiary text colors for reduced emphasis
  • Dark mode: Test contrast ratios; ensure 4.5:1 for body text, 3:1 for large text
