# Story 6.3 — Conversion dispatch on closed-won with value

**Epic:** 6 — Acquisition loop
**Status:** Ready

## Story

As TAG, I want to send a "purchase" conversion to Meta with the deal value when a prospect closes, so that Meta optimizes for high-value closes, not just closes.

## Context

Meta Conversions API accepts value in the conversion. Sending `value: 18000` (USD) teaches the algorithm "this ad bought someone who closed a $18k deal."

Without value, the algo treats all closes equal. With value, it learns to prioritize ads that close high-ticket deals.

Data: opportunity marked won (Story 2.6) → get contact → get utmAdId + monetaryValue → send to Meta with value.

## Acceptance criteria

1. Trigger: opportunity marked won via Story 2.6 (closeOpportunity).
2. Extract monetaryValue from the opportunity.
3. Call Meta Conversions API with:
   - event_name: "Purchase"
   - value: monetaryValue (USD)
   - currency: "USD"
   - user_data: hashed email/phone, fbc, fbp, utmAdId
   - event_id: opportunityId (idempotency)
4. Log to Firestore (Story 3.5).
5. On error: log and alert (don't block opportunity close).
