# Story 3.1 — Portfolio list with process stage

**Epic:** 3 — CSM portfolio and impersonation
**Status:** In Progress (Phase 1 Complete)

## Story

As a CSM, I want to see all my assigned clients with their Fulfillment stage, so that I know where each is in the onboarding/service ladder without opening each one.

## Context

Each client (location) has a Fulfillment opportunity tracking their process stage:
- `PR stages` → funnel setup
- `AP 2 - Ads Launched` → entry offer live
- `AP 4 - Closer Recruit` → upsell to closing team
- `AP 5 - Ascension` → expansion opportunity

CSMs need one view that says "these 12 clients, 3 launching ads this week, 5 need closer team talk, 2 ready to ascend."

## Acceptance criteria

1. A `/portfolio` route shows all locations assigned to the authenticated CSM.
2. Each client displays: name, current Fulfillment stage, health signal (AC 2 from 3.2).
3. Clicking a client enters that tenant with redirect (Story 3.3).
4. No data is cached; page refreshes show current stage and health.
