# Story 1.5 — Location-scoped routing

**Epic:** 1 — Foundation and access
**Status:** Ready
**Depends on:** 1.4

## Story

As a user with access to more than one tenant, I want the location to be part
of the URL, so that what I am looking at is unambiguous and shareable.

## Context

Routes currently read `GHL_LOCATION_ID` from the environment, so there is one
implied tenant and no way to express which client a page is about. A CSM with
twelve clients needs to move between them, and a link to "the pipeline" has to
mean a specific client's pipeline.

## Acceptance criteria

1. Routes become location-scoped:
   ```
   /l/[locationId]/pipeline
   /l/[locationId]/today
   /l/[locationId]/contacts
   /l/[locationId]/contacts/[contactId]
   ```
2. `requireLocationAccess()` runs before any data is fetched.
3. `/` redirects by role: single-location users to their location, multi-location
   users to a picker or portfolio.
4. A location switcher appears in the sidebar for multi-location users, listing
   only permitted locations.
5. The current client's name is always visible in the chrome. A CSM must never
   be uncertain which tenant they are acting in.
6. Old unscoped routes redirect rather than 404.

## Tasks

- [ ] Move `app/page.tsx`, `app/today`, `app/contacts` under `app/l/[locationId]/`
- [ ] Resolve and guard `locationId` in the layout
- [ ] Role-based redirect at `/`
- [ ] Location switcher component
- [ ] Show client name in the top chrome
- [ ] Redirects from old paths

## Dev notes

Guard in the layout rather than in each page. A layout runs before its pages,
so a new page under `/l/[locationId]/` inherits the check by construction —
one fewer thing to remember, and forgetting is the failure mode that matters.

Keep the switcher a plain list until there are enough tenants to need search.
Forty is close to that line; forty-plus is past it.

This story precedes impersonation (3.3) and is most of its plumbing: entering a
client tenant is navigating to their `locationId` with a CSM's claims, plus a
banner and an audit record.
