# Story 5.2 — Campaign template per offer

**Epic:** 5 — Onboarding and campaign launch
**Status:** Ready

## Story

As a CSM, I want to create a campaign by filling in a template (client name, budget, daily cap, pixel), so that campaign setup is one form, not a dozen clicks in Meta Ads Manager.

## Context

Each client has an "offer" (their value prop — e.g., "tax return prep", "bookkeeping"). TAG maintains one campaign template per offer: funnel structure, targeting, creative IDs, etc.

CSM inputs: client name, monthly budget, daily cap, GHL conversion pixel ID.

Template fills in the rest and creates a paused campaign (Story 5.4).

## Acceptance criteria

1. Route: `/onboarding/launch` or button on checklist (5.1).
2. Form: client name, offer (select from list), monthly budget, daily cap, pixel ID.
3. Dropdown: offer list (MVP: hardcoded; dynamically managed later).
4. Validation: required fields, budget ≥ $100, cap ≤ budget ÷ 30.
5. Submit → calls Story 5.4 (create paused campaign).

## Tasks

- [ ] Define offer list (hardcoded for MVP)
- [ ] Form: CampaignLaunchForm (client, offer, budget, cap, pixel)
- [ ] Validation: budget/cap checks
- [ ] Server action: initiates campaign creation (calls 5.4)
- [ ] Error: show clear message if creation fails
