# Story 4.1 — Meta System User and ad account access

**Epic:** 4 — Client owner dashboard
**Status:** Blocked — Meta setup required
**Owner:** [TBD]

## Story

As TAG, I want to read ad spend and performance data from Meta via the Marketing API, so that the Hub can display spend, leads, booked, showed, closed, and ROAS per ad account.

## Blocker

Meta Business Manager access and Facebook Marketing API setup. This gates the entire Epic 4.

### Setup required

1. **TAG Meta Business Manager**
   - Set up Business Manager account for TAG
   - Configure as the owner/admin entity

2. **Team access**
   - Add team members as users in Meta BM
   - Grant appropriate admin/analyst roles

3. **Client connections**
   - Clients must connect their own ad accounts to TAG's BM as partners
   - Establish clear ownership model: client-owned account with TAG partner access (recommended)

4. **Facebook Marketing API**
   - Register Hub app in Meta for Developers
   - Configure Marketing API permissions (`ads_read`, `ads_management` at minimum)
   - Verify `ads_management` standard access works at this volume; escalate to partner/premium access if needed
   - Set up app credentials for server-side API calls

## Acceptance criteria

1. TAG Business Manager is created and team members have access. ⨯ not started
2. At least one client ad account is connected to TAG BM with documented permissions. ⨯ not started
3. Hub app can authenticate to Meta Marketing API and fetch spend/performance. ⨯ not started
4. Sample ROAS calculation (spend + GHL outcomes joined on `utmAdId`) works end-to-end. ⨯ not started

## Dependencies

- **Blocked by:** Meta BM setup (external service setup, not engineering)
- **Blocks:** All of Epic 4 (stories 4.2–4.6)
- **Informs:** Story 6.1 (duplicate-conversion audit) — need to verify conversion pixel state before acquisition loop can dispatch

## Notes

- **Access tier risk:** Verify `ads_management` standard tier works for this account volume. If not, budget time for partner/premium access request.
- **Client onboarding:** Each new client must grant TAG partner access to their ad account — automate or document this as part of client onboarding workflow.
- **Conversion pixel state:** Before Epic 6 (acquisition loop) can safely send conversions, audit existing GHL integrations on each client pixel to prevent double-counting.
