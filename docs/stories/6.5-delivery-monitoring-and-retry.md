# Story 6.5 — Delivery monitoring and retry

**Epic:** 6 — Acquisition loop
**Status:** Ready

## Story

As TAG, I want to know if conversions reached Meta, and automatically retry if they failed, so that dropped conversions don't silently leave the algorithm blind.

## Context

Meta Conversions API can fail (network, auth, rate limit). Stories 6.2–6.3 log dispatch attempts to Firestore, but if a send fails, the conversion is lost and we don't know it.

This story monitors dispatch logs and retries failed sends on a schedule (hourly, 24h window).

## Acceptance criteria

1. Dispatch log (Firestore) tracks: event, timestamp, status (pending/sent/failed), error.
2. Sent: response from Meta included event_received: true.
3. Failed: error on send, or event_received: false.
4. Retry job runs hourly: query last 24h of failed conversions, retry up to 3 times.
5. Alert if conversions fail 3 retries (ops escalation, not user-facing).
6. Dashboard (Epic 4, optional): show conversion health (% delivered).
