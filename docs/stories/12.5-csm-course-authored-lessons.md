# Story 12.5 — CSM course authored lessons

**Epic:** 12 — Knowledge Base
**Status:** Ready
**Depends on:** 12.4

## Story

As a new CSM, I want the lessons the course update outline calls for but that were never recorded, so that the standard exists in one place instead of living only in the operating manual and in Austyn's head.

## Context

`assets/tag-skool-update-outline.pdf` maps a set of changes against the CSM-Training module list. A live crawl of the Skool classroom on 2026-08-21 confirmed that five of those items have **no source lesson to migrate**: the classroom returns 23 published lessons, all `state=2 / public=true`, and none of the following exist in it.

- `PROVEN ADS` — named in the outline as the base for the merged ads lesson
- `ACCESS HIGH LEVEL-FACEBOOK-…` — named as the home for the pixel-install traps
- Draft: `Using AI For Scripts And Assets`
- Draft: `Fulfillment Intro`
- New: `Client Intake Form Walkthrough`

So this is content authoring, not migration, and it is split out of 12.4 so the import is not blocked behind writing. Source material for all five exists in the assets already in the repo.

## Acceptance criteria

1. **Ad Copy & Callout Standards** body copy, authored from Manual §09.4. Includes the callout-specificity before/after ("high income attorneys" vs. "attorneys making over $400,000 a year") and the reason detailed targeting is left open so the callout carries the targeting. Lands on the lesson shell imported by 12.4.
2. **Pixel install and access** lesson, authored from Manual §08. Covers the two traps explicitly: the data set must be created from inside the ad account, never Events Manager or Business Settings; the pixel goes in Head Tracking Code, never Body. Also Meta Pixel manual install (not Conversions API), event mapped via Track Button to `Schedule`, and testing with the standard TAG test booking rather than personal contact info.
3. **Using AI For Scripts And Assets**, authored from Manual §06.1–06.3. Covers the one-asset-at-a-time rule, the modeling prompt verbatim, and the headline pattern.
4. **Fulfillment Intro**, authored from Ops Design Doc §3. Walks the architecture stage by stage, names the three CSM gates (intake quality, compliance review, launch review), and flags what is automated today versus still manual.
5. **Client Intake Form Walkthrough**, authored from `assets/tag-client-intake-form.pdf` and Manual §06. Walks all nine sections, shows where the branded form lives, and calls out which fields feed the AI script-modeling prompt so a thin intake is understood to produce a thin script.
6. **Compliance segment** added to Complete Tax Offer Structure, from Manual §09.6 and its Open Items: clients are licensed practitioners under Circular 230 and state board advertising rules, and no specific percentage or dollar tax-savings guarantee ships without the client's written sign-off. Its own clearly marked segment, not a footnote.
7. Updates to three existing lessons where the recorded video predates the current standard, added as lesson body text rather than re-recorded video: Wistia checklist (Manual §06.4), A2P full SOP sequence and its two silent-failure traps (A2P Setup SOP), REMINDERS exact templates and wait-step config (Manual §10.2).
8. Every lesson above is entered through the admin course editor or the import path from 12.4, and appears in the correct position in the CSM course.
9. No credential values are introduced into any authored lesson text by this story.
10. Gate passes: `ng build --configuration production && ng lint && ng test --watch=false`.
