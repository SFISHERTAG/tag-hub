

## Post-implementation change: typed Meta Graph responses (lint gate)

Files this story references were changed by a lint cleanup, not by further
work on the story itself. Status is unchanged.

`lib/meta/ads.ts`, `campaigns.ts` and `creatives.ts` typed their Graph API
responses as `any`. Each now declares the raw response shape it actually
requests (`RawAdInsightsRow`, `RawCampaign`, `RawInsights`, `RawAd`), which
makes two things explicit that `any` hid: Meta returns every numeric field as
a string, and it omits fields rather than nulling them, so each mapping now
carries a stated fallback. No API calls, fields, or computed values changed.
One incidental cleanup: `getCampaignMetrics` was parsing `spend` and
`conversions` twice per call; it parses each once now.
