# Story 4.2 — Spend and delivery by ad

**Epic:** 4 — Client owner dashboard
**Status:** Blocked (Meta credentials not actually live — see dev notes)

## Story

As a client owner, I want to see how much I'm spending per ad creative, so that I can see which ones are worth the budget.

## Context

Meta Marketing API returns spend per ad via the Ads API. GHL returns booked appointments and closed deals per contact, which are attributed to an ad via `utmAdId` on the contact record.

This story surfaces spend alone (Meta API). Story 4.4 joins it to outcomes (booked, showed, closed) to compute ROAS per ad.

## Acceptance criteria

1. Fetch spend per ad from Meta Marketing API (daily, last 30 days).
2. Display as a table: Ad name, spend (USD), spend trend (↑/↓ vs 7-day avg).
3. Sort by spend descending (biggest spenders first).
4. "As of" timestamp (Story 4.5) shows when this data was last fetched.
5. No data without Meta setup (Story 4.1) — show a setup notice instead.

## Tasks

- [x] Create `getAdSpend(adAccountId, days=30)` function calling Meta Ads API
- [x] Parse response into { adId, adName, spend, spend7d }
- [x] Component: AdSpendTable with sort + trend indicators
- [x] Page: `/l/[locationId]/dashboard` showing spend table + "as of" timestamp
- [x] Error handling: if Meta API fails, show clear message
