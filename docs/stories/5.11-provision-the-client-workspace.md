# Story 5.11 — Provision the client workspace on Closed Won

**Epic:** 5 — Onboarding and campaign launch
**Status:** Done — deployed and live as `phase1-provisioning`

## Story

As TAG, when a deal is marked Closed Won and someone ticks "Initiate
Onboarding", I need the client's entire workspace to exist without anyone
assembling it by hand, so onboarding starts the same way every time.

## Why this story exists at all

This work has been running in production for months as a thing called "Phase 1".
It had no story, no epic and no Status field, which meant nothing in this repo
could tell you whether it was working. Its siblings stopped working entirely and
nobody noticed (5.12, 5.13).

Every guard here watches `docs/stories/*.md`. A deployment named after a phase
is invisible to all of them. That is the whole reason this file exists — see
`AGENT_COORDINATION.md` §11.

## What it does

Triggered by a GHL webhook when the "Initiate Onboarding" checkbox is ticked on
a deal in Closed Won. In order:

1. Clone the GHL sub-account from the template (`cloneLocation`)
2. Create the client Slack channel and invite them as a single-channel guest
3. Create their folder on the Shared Drive
4. Add their email to the OTP whitelist so they can sign in
5. Create the Fulfillment pipeline opportunity
6. Provision their Hub user and role claims (`provisionClientOwner`, story 1.8)
7. Email them the intake form, and send the internal confirmation

Implementation: `functions/src/webhooks/phase1-provisioning.ts`.

## Acceptance criteria

1. [x] A Closed Won deal with the checkbox ticked produces a cloned sub-account, Slack channel, Drive folder, OTP whitelist entry, Fulfillment opportunity and Hub user
2. [x] The endpoint refuses unauthenticated callers
3. [x] Re-delivery of the same webhook does not double-provision (`hasBeenProcessed` / `claimEvent`)
4. [ ] **The endpoint is verified reachable and enforcing as part of the definition of done, not by someone checking later.** Not met: this was verified today, by hand, months after deployment

have been true for months. AC4 is what would have caught 5.12 and 5.13 dying,
and no story asserted it because no story existed.
