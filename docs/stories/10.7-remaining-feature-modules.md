# Story 10.7 — Remaining feature modules

**Epic:** 10 — Angular migration
**Status:** In Progress

## Story

As the team maintaining this codebase, I want the last Next screens ported and
then deleted, so that every feature exists in exactly one place and the Next
deployment is an API host serving a bundle, nothing more.

## Context

What is left after 10.5 and 10.6: onboarding (checklist and the launch wizard),
FLOW, courses, admin (tenants, users, courses), success, bug reports, the setter
dashboard, and the Meta, Drive and Slack service modules that have no screens of
their own but back widgets and tabs elsewhere.

**Legacy removal moved out of this story on 2026-08-21.** This story was titled
"Remaining feature modules and legacy removal" and contained no acceptance
criterion or task for the removal half. Sweeping `legacy/`, 142 files, and
removing the four exemptions that carry it is now Story 10.8, which depends on
this one. What stays here is porting the last features; what leaves is deleting
the directory they were ported from.

This story is where the migration either finishes or acquires a permanent tail.
The failure mode is leaving three Next screens alive because they are small,
which keeps the whole Next rendering path, its layout, its auth wiring and its
`lib/` imports in the tree forever. The deletion is the deliverable, not the
cleanup after it.

**One open question this story must answer first.** The setter dashboard has no
home in `docs/frontend-file-tree.md`. It reads GHL speed-to-lead data, so it is
plausibly `features/ghl/`, but it is a distinct role's whole workspace rather
than a GHL screen. Decide and record it in the file tree before building, since
the tree and the lint zones are written from each other.

## Acceptance criteria

1. `features/onboarding/`, `features/flow/`, `features/courses/`,
   `features/admin/`, `features/success/`, `features/bug-reports/` exist, lazy
   and `OnPush`.
2. `features/meta/`, `features/drive/` and `features/slack/` hold their typed
   services and any widgets, and import no sibling integration.
3. The setter dashboard has a recorded home in the file tree and lives there.
4. Every remaining server action has an endpoint equivalent, and
   `grep -rl '"use server"' app` returns nothing.
5. No file under `app/` renders a page. `app/api/**` and the bundle host remain.
6. `docs/frontend-file-tree.md` and `web/eslint.config.js` agree, in the same
   commit, as they must.
7. `ng build --configuration production && ng lint && ng test --watch=false`
   pass, and the root gate passes for the API-only Next app.

**The file tree has drifted from the code, in both directions, and AC6 cannot
see it.** AC6 compares the document against the lint config, and those two do
agree. Neither is compared against the tree. Counted at `8787c50`:

- Recorded in `docs/frontend-file-tree.md`, absent from the code: `meta/`,
  `drive/`, `slack/`, `success/`.
- Present in the code, absent from the document: `knowledge-base/`, `setter/`,
  `settings/`.

Seven modules out of step, and every guard in the repository reports agreement,
because the only agreement anyone checks is between two documents. AC3 catches
exactly one of the seven, `setter/`, and only because a criterion happened to
name it. This is the same shape as the Status problem this pass exists to fix: a
contract that is consistent with another contract and wrong about the code.
Recorded, not fixed. Reconciling the file tree is not a story-status correction,
and moving a directory in one place means moving it in the other in the same
commit, which is a change this pass has no mandate to make.

## Dev notes, deletion is the deliverable

Epic 10's rule is that when an Angular feature passes its gate, the matching
Next pages are deleted in the same commit. This story is where that rule pays
off or is quietly abandoned.

A useful check at the end: the count of `page.tsx` files under `app/` should be
zero, and `grep -rl '"use server"' app` should return nothing. Both are cheap to
run and neither can be satisfied by a screen that merely looks ported.

## Dev notes, what stays

`app/api/**`, `lib/`, `functions/`, and the Next app as a same-origin host for
the Angular bundle. `hub_session` is httpOnly and `SameSite=lax` and only
survives that topology, so the host is not incidental.
