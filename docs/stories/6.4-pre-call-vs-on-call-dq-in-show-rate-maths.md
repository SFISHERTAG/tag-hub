# Story 6.4 — Pre-call vs on-call DQ in show-rate maths

**Epic:** 6 — Acquisition loop
**Status:** Done

## Story

As TAG, I want show-rate and DQ-rate to account for when a prospect was disqualified (before or during the call), so that targeting, reminder, and closer performance issues are not hidden by collapsing them.

## Context

Two kinds of DQ:
- **Pre-call DQ:** marked "invalid" before appointment start. Nobody showed up, appointment should never have been booked. This is a targeting or lead quality failure — should not count in show-rate denominator.
- **On-call DQ:** marked "invalid" during or after the call. Real person showed, they didn't qualify. This counts as "showed" for the denominator, but is a close-rate issue, not a show-rate issue.

Story 2.3 already captures timing via `classifyTiming()`. This story uses it to separate the metrics.

## Acceptance criteria

1. Show rate = showed ÷ (booked − pre-call DQ)
   - Pre-call DQs drop from denominator entirely.
   - Only "showed" counts as showed.
2. On-call DQ count = on-call DQs only (not in show-rate, separate metric).
3. Dashboard (Epic 4) displays:
   - Show rate (clean denominator)
   - Close rate (closed ÷ showed, where on-call DQ counts as showed)
   - DQ rate breakdown (pre-call vs on-call separately)
4. Funnel (Story 4.3) shows: Leads → Booked → Showed (correct denominator) → Closed.
