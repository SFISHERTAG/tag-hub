# Story 1.3 — Identity Platform sign-in

**Epic:** 1 — Foundation and access
**Status:** Ready

## Story

As a TAG staff member or client user, I want to sign in to the Hub with my own
account, so that the app knows who I am before it shows me anything.

## Context

Nothing in the Hub is currently authenticated. Every route reads
`GHL_LOCATION_ID` from the environment and serves the same single tenant to
anyone who opens it. That is fine for development against TAG's own
sub-account and unacceptable the moment a client user or a second tenant
exists.

Identity Platform is already enabled on `tag-success-hub`.

## Acceptance criteria

1. An unauthenticated request to any route other than the sign-in page
   redirects to sign-in.
2. Email/password sign-in works for an invited user. Self-signup is disabled —
   accounts are created by TAG, not requested.
3. The session is verified server-side on every request. A forged or expired
   token is rejected, not trusted from the client.
4. Sign-out clears the session and returns to sign-in.
5. `GHL_LOCATION_ID` no longer determines what a signed-in user sees. It may
   remain as a development fallback only.

## Tasks

- [ ] Enable email/password provider; disable self-signup
- [ ] Add Firebase Admin SDK for server-side token verification
- [ ] Sign-in page and server action
- [ ] Session cookie, httpOnly and secure in production
- [ ] `middleware.ts` gating all routes except sign-in and `/api/oauth/*`
- [ ] Sign-out
- [ ] Seed the first TAG admin account

## Dev notes

`/api/oauth/*` must stay unauthenticated — it is the GHL install callback and
GHL will not carry a Hub session. It has its own CSRF protection via the
`state` parameter and cookie comparison.

Verify the ID token server-side on every request rather than trusting a client
claim. The whole tenant-isolation model rests on the role and location list
being trustworthy, and a client-supplied claim is neither.

Do not build a password reset flow yet. With a handful of TAG accounts, manual
reset is cheaper than the surface area.
