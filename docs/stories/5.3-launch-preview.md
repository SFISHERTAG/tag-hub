# Story 5.3 — Launch preview

**Epic:** 5 — Onboarding and campaign launch
**Status:** Ready

## Story

As a CSM, I want to see exactly what's about to be created before I launch, so that I don't accidentally launch the wrong funnel or budget to the wrong pixel.

## Context

After filling the form (5.2), CSM sees a preview of the campaign before the "activate" button appears. Preview shows:
- Campaign name
- Ad set name + targeting
- Ads (preview images if available)
- Budget and daily cap
- Pixel ID (validation: will this receive conversions?)

Only after reviewing and confirming does "activate" become available (Story 5.5).

## Acceptance criteria

1. Route: `/onboarding/launch/preview` (after form submit).
2. Display: campaign structure, budget, pixel, targeting, creative thumbnails.
3. "Looks good / Edit / Cancel" actions.
4. Edit → back to form (5.2) with values retained.
5. Cancel → back to checklist (5.1).
6. Confirm → calls Story 5.5 (activate).

## Tasks

- [ ] Render preview from template + form inputs
- [ ] Component: CampaignPreview showing full structure
- [ ] Links: Edit (back to form), Cancel (to checklist), Confirm (to 5.5)
- [ ] Verify pixel ID is valid in Meta (optional)

## Dev notes

Preview is a read-only view. No writes happen until "confirm" → 5.5.

Creative images: if available in template, show thumbnails. If not, show placeholder.
