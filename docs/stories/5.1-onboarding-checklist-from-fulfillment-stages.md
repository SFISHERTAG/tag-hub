

## Post-implementation change: stage-name parsing (resweep High)

Status is unchanged.

`isFulfillmentStage` required an exact `"AP2"`, and GHL's real stage names
carry a label after the code ("AP 2 - Ads Launched"). The exact match never
matched, so every client past PR1 saw "Stage unrecognized" and an empty
checklist rather than their tasks, and the AC4 stage-move task completion
never fired either. `parseFulfillmentStage` in `lib/onboarding/stage-tasks.ts`
extracts the code from the real name; both call sites use it. The task map
itself is unchanged.
