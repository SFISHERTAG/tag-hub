# Story 13.1 — createOpportunity in the typed service layer

**Epic:** 13 — Lifecycle handoff and churn prevention
**Status:** Draft
**Depends on:** none

## Story

As the Hub, I want one typed `createOpportunity` in `lib/ghl/`, so that creating
an opportunity does not require reaching into the duplicate GHL client.

## Context

`lib/ghl/opportunities.ts` can read opportunities, move their stage, and close
them. It cannot create one. The only `createOpportunity` in the codebase lives in
`functions/src/ghl.ts`, which is the duplicate GHL client the audit flagged
against `lib/ghl/` and which CLAUDE.md names explicitly as the thing not to
deepen.

Every story below this one needs to create an opportunity. Adding a second
implementation, or importing the functions-side one, would make the split
permanent at exactly the moment it becomes load-bearing.

This story is deliberately small and has no user-visible behavior. It exists so
that 13.3 has something correct to call.

## Acceptance criteria

1. `createOpportunity(locationId, input)` exists in `lib/ghl/opportunities.ts`
   and goes through `ghl()` like every other call in that module, so it inherits
   `requireLocationAccess`, token resolution, and the error contract.
2. Input carries at minimum `pipelineId`, `pipelineStageId`, `name`,
   `contactId`, `status`, and `monetaryValue`.
3. The returned opportunity id is typed, not `any`.
4. Unit tests cover a successful create and a GHL error surfacing as `GhlError`
   rather than a silent null.
5. `functions/src/ghl.ts#createOpportunity` is either removed or reduced to a
   call into the shared path. If it cannot be removed in this story, the reason
   is written down here rather than left implied.
6. No new caller of `functions/src/ghl.ts` is introduced anywhere.

## Tasks

- [ ] Add `createOpportunity` to `lib/ghl/opportunities.ts`
- [ ] Type the request and response, no `any`, no non-null assertions
- [ ] Unit tests for success and error paths
- [ ] Resolve or document the `functions/src/ghl.ts` duplicate
- [ ] Gate: `npm run test`, `npm run lint`, `tsc --noEmit`
