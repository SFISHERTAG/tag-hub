# Story 2.1 — Pipeline board

**Epic:** 2 — Closer workspace
**Status:** Done

## Story

As a closer or TAG sales rep, I want to see every deal grouped by pipeline
stage, so that I know what to work without opening GoHighLevel.

## Acceptance criteria

1. Every pipeline for the location renders as its own board, stages ordered
   by position. ✓
2. Deals are grouped into their stage column with a running count and
   stage-total value. ✓
3. A status filter (open / won / lost / abandoned / all) narrows the board;
   open is the default because abandoned records outnumber live ones on this
   location. ✓
4. A deal shows contact name, company, source, and value when present. ✓
5. A deal sitting 14+ days in its current stage is flagged as stale. ✓
6. Missing configuration (no location) and GHL failures render a distinct
   notice instead of a blank or crashed page. ✓

## Implementation

`app/page.tsx`, reading `lib/ghl/pipelines.ts` (`getPipelines`) and
`lib/ghl/opportunities.ts` (`getOpportunities`, `groupByStage`, `daysSince`,
`formatMoney`). Server component, no client-side state; the status filter is
a query-string link (`?status=`), not a form. Staleness reads
`lastStageChangeAt`, falling back to `updatedAt`.
