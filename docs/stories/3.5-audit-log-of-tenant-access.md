# Story 3.5 — Audit log of tenant access

**Epic:** 3 — CSM portfolio and impersonation
**Status:** Done

## Story

As TAG leadership, I want an audit record of every time a CSM enters a client's account, so that we can answer "who touched this client's data and when" if a client asks.

## Context

This story is **not optional** and ships with 3.3. Entering a client's data without a record is a compliance and accountability gap that only becomes apparent when asked by a client or regulator.

Every impersonation creates an entry:
- CSM user ID
- Client location ID
- Entry timestamp
- Exit timestamp (when CSM leaves)
- Any writes made while impersonated (marked appointments, closed deals, etc.)

## Acceptance criteria

1. Firestore collection: `locations/{locationId}/auditLog` with documents per session.
2. On entry (Story 3.3): create audit entry with CSM ID, entry time, client ID.
3. On exit (Story 3.4): update same entry with exit time.
4. Every write while impersonated includes a reference to this audit entry.
5. Audit log is immutable — no deletes, only appends.
