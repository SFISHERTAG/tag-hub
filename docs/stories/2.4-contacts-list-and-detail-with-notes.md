# Story 2.4 — Contacts list and detail with notes

**Epic:** 2 — Closer workspace
**Status:** Done

## Story

As a closer, I want to search contacts and see one contact's attribution and
notes, so that I can prep for or follow up on a call without switching to
GHL.

## Acceptance criteria

1. Contacts can be searched by name, email, or phone from a single search
   box. ✓
2. The list shows name, company, email, phone, source, and date added. ✓
3. A contact's detail view shows first-touch and last-touch attribution
   separately, since one names the ad that found the lead and the other the
   ad that brought them back. ✓
4. A contact carrying Meta identifiers (`fbc`, `fbp`, or `utmFbclid`) is
   visibly marked "Meta trackable." ✓
5. Notes render newest first, with a form to add a new note without leaving
   the page. ✓
6. Missing configuration, GHL failures, and an unknown contact id each
   render a distinct state (setup notice, error notice, 404). ✓

## Implementation

`app/contacts/page.tsx` (list, search) and
`app/contacts/[contactId]/page.tsx` (detail), reading `lib/ghl/contacts.ts`
(`searchContacts`, `getContact`, `getNotes`, `firstTouch`, `lastTouch`,
`hasMetaIdentifiers`, `displayName`). Note creation is
`app/contacts/[contactId]/note-form.tsx` (client) calling the `createNote`
server action in `app/contacts/[contactId]/actions.ts`, which calls
`addNote` in `lib/ghl/contacts.ts`.

Attribution is normalized in `lib/ghl/contacts.ts` because GHL shapes it
differently by endpoint: the contact list returns an `attributions` array,
the single-contact route returns `attributionSource` and
`lastAttributionSource` objects.
