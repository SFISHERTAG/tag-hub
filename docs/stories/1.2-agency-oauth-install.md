**Status:** Blocked — requires GHL account consolidation (OAuth install complete as of 2026-08-09)

## Story

As TAG, I want one agency-level install that reaches every sub-account, so that
adding a client does not mean provisioning another credential.

## Blocker

~~Marketplace app installation is an Agency Owner action.~~ ✓ Completed 2026-08-09.

Remaining blocker: 23 accounts must be consolidated into a sub-account model in

4. All sub-accounts (23 current, 40 planned post-migration) become reachable. ⨯ pending GHL account consolidation

## Implementation notes

Built: `app/api/oauth/install`, `app/api/oauth/callback`, `lib/ghl/oauth.ts`,
`lib/ghl/store.ts`.

Marketplace app configuration that this required, learned the hard way:
**Target User: Sub-Account** with **Agency & sub-account** install. Agency-only
targeting locks out all 144 sub-account scopes, which would leave the app able
to list sub-accounts and read nothing inside them. Target user cannot be
changed after app creation.

Redirect URIs may not contain the string `ghl`.
