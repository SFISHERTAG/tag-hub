As TAG, I want one agency-level install that reaches every sub-account, so that
adding a client does not mean provisioning another credential.

## Implementation notes

Built: `app/api/oauth/install`, `app/api/oauth/callback`, `lib/ghl/oauth.ts`,
`lib/ghl/store.ts`.

Marketplace app configuration that this required, learned the hard way:
**Target User: Sub-Account** with **Agency & sub-account** install. Agency-only
targeting locks out all 144 sub-account scopes, which would leave the app able
to list sub-accounts and read nothing inside them. Target user cannot be
changed after app creation.

Redirect URIs may not contain the string `ghl`.

_2026-08-18: `lib/ghl/store.ts` gained fields/functions for the follow-up queue (story 2.8) in the same commit as the location-scoped routing migration. Incidental to this story — no OAuth/token-storage behavior changed._

_2026-08-22: agency tokens are now keyed by company. They shared one Firestore
document (`ghl/agency`), and `saveAgencyToken` set it unconditionally, so any
outside agency completing a company-level install overwrote ours, `companyId`
included. Every later mint for every one of our own sub-accounts would then have
been attempted against the wrong company and failed: one outside install, whole
portfolio dark, no error until requests started coming back empty. Tokens now
live at `ghl/agency/companies/{companyId}`, the first install recorded becomes
the primary and is never reassigned, and `ghl/agency/locations/{id}` carries
`agencyCompanyId` so a re-mint returns to the agency that owns the location. The
legacy root token migrates itself on first read, so the live install keeps
working with no reinstall. This matters now rather than later because AC#4's
path for clients who stay in their own agency is the direct install, which means
inviting outside agencies to authorize the app. Doing that before this fix would
have been the trigger. Files: `lib/ghl/store.ts`, `lib/ghl/tokens.ts`,
`app/api/oauth/callback/route.ts`, `lib/ghl/store.test.ts`,
`docs/data-model.md`._
