## Story

As a client owner, I want to see ROAS (revenue ÷ spend) per ad creative, so that I know which creatives are worth scaling and which need to be paused or refreshed.

## Context

This is the centerpiece of the Hub. It joins spend per ad (4.2) to outcomes per ad via the `utmAdId` on GHL contacts:

```
spend_per_ad = Meta Ads API
revenue_per_ad = sum(monetaryValue) for contacts where utmAdId = ad_id and status = "won"
ROAS = revenue_per_ad / spend_per_ad
```

Story 2.6 ensures `monetaryValue` is accurate (CSMs mark deals won with explicit value).

## Acceptance criteria

1. For each ad in last 30 days: query all contacts with that `utmAdId` and status="won".
2. Sum their `monetaryValue` as revenue_per_ad.
3. Divide by spend_per_ad from Meta API (Story 4.2).
4. Display as table: Ad name, spend, revenue, ROAS, ← → (trend vs 7-day avg).
5. Sort by ROAS descending (best performers first).
6. Blank ROAS if no conversions or zero spend (avoid division errors).

ROAS trend: compare 7-day avg ROAS to 30-day avg. "↑ trending" or "↓ declining" helps spot when a creative is losing efficiency.
