

## Post-implementation change: portfolio resilience (resweep High)

Status is unchanged.

`app/portfolio/page.tsx` fetched every tenant with `Promise.all(getTenant)`,
which rejects on the first failure, so one unreachable tenant record crashed
the client switcher for every other client. Changed to `Promise.allSettled`:
tenants that resolve render, and the number that did not is shown rather than
silently missing. `getTenant` itself is unchanged.
