# Story 2.2 — Day view with outcomes

**Epic:** 2 — Closer workspace
**Status:** Done

## Story

As a closer, I want to see today's appointments across every calendar in one
list, so that I don't check each calendar separately.

## Acceptance criteria

1. Appointments for yesterday, today, or tomorrow render in one
   time-ordered list, merged across every calendar on the location. ✓
2. Each row shows time, title, and the calendar it belongs to. ✓
3. A cancelled appointment is marked as such inline rather than hidden. ✓
4. The page shows a running count of appointments and how many already
   carry an outcome. ✓
5. Missing configuration and GHL failures render a distinct notice instead
   of a blank or crashed page. ✓

## Implementation

`app/today/page.tsx`, reading `lib/ghl/appointments.ts` (`getAppointments`,
`getCalendars`, `dayRange`, `formatTime`). Day selection is a query-string
link (`?day=`). `getAppointments` fans out to every calendar in parallel and
merges the result, since GHL has no single "all calendars" endpoint.
