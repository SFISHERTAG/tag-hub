

## Post-implementation change: live role claims (resweep High / Auth & Admin)

`lib/auth/session.ts`, which this story references, changed for a
cross-cutting auth fix. Status is unchanged.

`getSession` now resolves role grants from the user's live custom claims
rather than from the 14-day-old snapshot baked into the session cookie, so an
admin's role change takes effect within 60 seconds instead of at the user's
next sign-in. Claim parsing moved into a shared `parseRoleGrants` helper; both
claim formats are still supported. A failed live lookup falls back to the
cookie's claims rather than signing the user out.
