# Story 3.4 — Impersonation banner and read-only default

**Epic:** 3 — CSM portfolio and impersonation
**Status:** Ready

## Story

As a CSM, I want an unmistakable banner showing me I'm viewing a client's account, with a quick exit, so that I never accidentally make changes as if they were my own work.

## Context

When a CSM impersonates a client (Story 3.3), they see that client's data. The banner makes it visually clear this is not their own account. The banner also offers a one-click exit.

Read-only default means: CSM can read client data, but certain write operations are restricted or logged separately (e.g., marking appointments, closing deals). This is a UX concern, not a hard block — the intent is to make accidents visible, not to prevent intentional work.

## Acceptance criteria

1. When impersonated (`?impersonate=true`), a banner appears at the top of every page saying "You are viewing [Client Name]'s account."
2. Banner is visually distinct: high contrast, fixed position, unmissable.
3. Banner has an "exit" button that clears impersonation and returns to `/portfolio`.
4. While impersonated, all writes (marking appointments, closing deals, etc.) are logged with CSM's user ID (not client ID) for auditability.
