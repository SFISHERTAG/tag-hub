# Story 1.1 — Token resolution seam

**Epic:** 1 — Foundation and access
**Status:** Done

## Story

As the Hub, I want a single place that answers "give me a token for this
location", so that moving from one-location development to 40 tenants changes
one function and no call sites.

## Acceptance criteria

1. Callers request a token by location and never learn its origin. ✓
2. Resolution order: cached location token → direct-install refresh → agency
   mint → development PIT. ✓
3. Firestore being unreachable falls through to the PIT rather than crashing,
   so local work continues without application default credentials. ✓
4. A location with no available credential raises a named error identifying
   the location, not a bare 401. ✓

## Implementation

`lib/ghl/tokens.ts`. Every call in `lib/ghl/client.ts` takes `locationId` as
its first argument — there is no ambient current location, so a query cannot
read another tenant's data by omission.
