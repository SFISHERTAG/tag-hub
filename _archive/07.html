Part B · Section 07

Funnel build

Three pages in GoHighLevel. Roughly three minutes once you have a snapshot.

Do this once, save it forever

After your first clean build, take a snapshot and deploy every subsequent funnel from it. This is the single biggest time saver available to you.

07.1 Create the shell
  1. Sites → Funnels → New Funnel, name it, build from scratch.
  2. Add the first step, name the page VSL, path /VSL.
  3. Connect the Client's domain.
07.2 VSL page
  1. Headline — attention statement naming the audience. Size 21, heavy.
  2. Headline — guarantee and offer. Size 39, 900 heavy.
  3. Video — set type to Custom Embed, paste the Wistia embed code.
  4. Button — "Schedule a Free Demo", subtext "Limited spots available." Sizes 22 and 15, heavy then bold. Link to next step. Background #EBC507, black text.
  5. Headline — disclaimer, rewritten for the Client. Size 12, with spacing above.
  6. Save, or confirm autosave is on.
07.3 Mobile sizing — before you clone
  1. Switch to Mobile mode on the VSL page.
  2. Headline 1 → 14. Headline 2 → 16.
  3. Button → unchanged. Disclaimer → 8.
  4. Now clone, and mobile settings carry through.

Do this on step one before cloning anything. Mobile layout does not carry over once you've already cloned. Fixing it afterward means redoing every step by hand.

07.4 Application page
  1. Clone Funnel Step from VSL. Rename immediately: step name "App", path /app. Update the step.
  2. Rewrite the top headline via ChatGPT to close the loop. Size stays 39.
  3. Delete the original headline and the button. Keep the disclaimer.
  4. Add Calendar, select the Client's GoHighLevel calendar, set redirect to "Go to Next Step."
  5. Add an underlined line above it, e.g. "Schedule a strategy call", with a blank spacer.
07.5 Pre-call page
  1. Clone Funnel Step from Application. Rename to "Pre-Call", path /ty.
  2. Replace the headline: "Important — after adding the event to your calendar, watch the video below so we can hit the ground running on your call." Size 20.
  3. Delete the calendar element.
  4. Add Video, Custom Embed, for the pre-call video.
  5. Add a second headline: "Add the event to your calendar — go to your email and click Add to Calendar." Size 23, bold.
Rename before you edit

Cloned steps keep the word "clone" in the name and inherit the wrong path. Rename and update the path immediately after cloning, before touching content. Leftover clone names in a live URL are visible to the Client's prospects.
